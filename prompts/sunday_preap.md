CFB Sunday pre-AP build for Heath's CFB Top 25 dashboard artifact (https://claude.ai/artifact/3xNnYRHpv5kim7XRkquRdn). Runs early Sunday, after Saturday's games and BEFORE the AP poll. It (A) grades the week's picks and projections, (B) builds Claude's Top 25 as a locked, poll-free ballot, and (C) updates the Player Model and its Top 25. Heath's rule: Claude's Top 25 must not use any poll (AP, Coaches, Commissioner's, JP) and must be out before the AP poll. He is a Missouri fan: never let that affect any ranking.

Setup
- Load ArtifactData via ToolSearch ("select:ArtifactData"). Load the built-in browser tools with one ToolSearch for the *Claude_Browser__* prefix (ESPN only loads reliably there; run every ESPN fetch with javascript_tool on an espn.com tab). Long scripts: window.__p = (<script>).then(v=>window.__out=v).catch(e=>window.__out="ERR "+e.message), then poll window.__out.
- git clone https://github.com/heathhukari/cfb-data (or git pull). If refused, call add_repo (owner heathhukari, repo cfb-data, access "push") and use the clone command it returns. Never ask for or handle the CFBD API key.
- Read doc code/claude-model (gradeAll, pullTeams, rankings, howToRankings). Large docs: write JSON to a local file and pass file_path. Never "set" an existing doc without its if_version.
- Moving data from the browser to the workspace: return COMPACT JSON from the browser (arrays, ids instead of names) and read it in slices of ~15,000 characters; never page full ESPN payloads through the conversation.

Ids: P = the newest "polls" doc (last week's AP poll). The ballot id is NEXT = <season>-w<P.week+1, two digits>, sortKey = P.sortKey + 1, label "Week <P.week+1>". If top25/NEXT already exists with builtBeforeAP true, skip part B (the ballot is locked).

A. GRADE THE WEEK
1. Find the newest "picks" doc K with any pick whose result is null. Read predictions/<K id>, darkhorses/<K id>, records/<season>.
2. On the espn.com tab run the stored gradeAll with window.__in = {season, week: K.week, predGames, picks: K.picks, darkhorses: {darkHorses, sleepers}, newPoll: null}. (If the payload is too big to paste, fetch the finals in the browser in compact form and run gradeAll in node in the workspace with a fetch() shim that serves those finals; the logic must be the stored gradeAll.)
3. Verify no frozen pick field changed (line, madeAt, side, market, gameId, edge, bestBet, bestRank, notes). Write one batch (if_version on each): predictions/<K id>.games; picks/<K id>.picks + gradedAt; darkhorses/<K id> darkHorses + sleepers (dark-horse hits stay null until Monday's poll); records/<season>.weeks (replace the entry with the same week). Note pending (not yet final) game ids.

B. CLAUDE'S TOP 25 BALLOT (poll-free)
4. Build names = {espnId: name} from the "teams" collection. On the espn.com tab run the stored pullTeams (window.__in = {season, names: {}}), then reduce in the browser to: teams [[id, conf, fpi, fpiRk, sor, po, sp, spRk, own]] and results "w,hid,aid,hs,as,neutral,conf;..." and bring that to the workspace; rebuild wins/losses from results and names from the map. Report meta.unmatchedSp.
5. In node, evaluate the stored rankings text (engine v6) and call claudeRankings with: meta {season, week: P.week+1, sortKey, label, through: Saturday's date, updatedAt}, poll: P, prevPoll: P, coaches: {}, colley: [], massey: [], teams, results, future: [], lastWeek (this week's results with names), prev: {top25: newest top25 doc}, cfp: [], jp: [], commish: [], standings: {}, predGames: []. Confirm top25.blendWeights is {claudePower: 1, jp: 0, polls: 0}.
6. Add to the top25 result: builtBeforeAP: true, basis: "Built <Sun Mon D, h:mm AM> ET from Saturday's results, before the AP poll. Inputs: SP+ (ESPN, <article date> edition), FPI and strength of record (ESPN, current feed), and Claude's own results model refit through <Saturday date>. AP rank shown is last week's poll.", pending: one sentence naming any game not final at build time (or omit). Write top25/NEXT with "set".

C. PLAYER MODEL
7. In the repo, set collect/run.json to {"job": "weekly", "year": "auto", "week": "auto", "maxCalls": 18, "note": "Sunday pre-AP pull <date>"} and commit + push (this starts the CFBD collector). git pull every ~2 minutes for up to 20 minutes until a new data/manifests/weekly-*.json appears for the week just played. If it never appears, say so and continue with the data already there.
8. Save the step-4 teams as teams.json [{name, sp, fpi, own}], save top25/NEXT (step 6 result) and a predictions file {"games": []}. Run: python model/build_inputs.py <season> <P.week+1> teams.json top25.json pred.json, then python model/player_model.py <season> <P.week+1> <newest data/<season>/injuries_wNN.json>. Sanity: 25 teams, QB adj within ±6, injury total ≥ −10 (games may be 0; Monday adds them).
9. Grade last week's PM lines: python model/grade.py <season> <P.week> (uses CFBD finals from step 7). If model/out/playermodel_<season>_w<P.week>.json is missing, save doc playermodel/<P id> there first.
10. One batch: update playermodel/<P id> {games (graded), gradedThrough} with if_version; set playermodel/NEXT = model/out/playermodel_<season>_w<NN>.json + record (model/out/pm_record_<season>.json) + updatedAt + note "Built early Sunday from Saturday's results and Claude's pre-AP Top 25. Injuries: <source/date>. This week's game lines are added Monday." (if_version if it exists). git add data model/out, commit "Pre-AP week <N>", push.

Report in five lines: 1) grading (ATS, totals, best bets, SU; pending games); 2) Claude's Top 25 top 10 with records; 3) biggest movers vs last week's Claude Top 25; 4) PM top 5 and the season PM vs Claude vs Vegas average miss; 5) anything missing (CFBD run, unmatched SP+ names, desktop browser unavailable).
